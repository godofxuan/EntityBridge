# 服务权限、查询与复核候选（更新至 v0.3）

本轮审查于 2026-09-12 完成。服务定位为监听 loopback 的单工作空间应用，尚未提供公网部署、SSO 或多租户隔离。

## 已修复的访问问题

正常 `serve` 原先只有写操作要求令牌，企业目录、记录关联、固定版本 CSV 和网页可以匿名读取。新增回归先验证匿名 `/entities` 实际返回 200，再修复为 401。现在所有企业数据读取都要求有效的 bearer token 或登录会话；匿名 `/health` 只返回服务状态。

| 角色 | 已发布企业与证据 | 人工判断、撤销、管理历史 | 导入、运行、发布 |
|---|---|---|---|
| viewer | 可读取 | 不可操作 | 不可操作 |
| reviewer | 可读取 | 可操作 | 不可操作 |
| admin | 可读取 | 可操作 | 可操作 |

权限同时应用于 API 和 HTML 表单；仅隐藏按钮不构成访问控制。未发布候选的企业数据不可通过指定 revision 绕过查询边界。令牌配置校验 ASCII、非空白、角色以及身份格式；应用复制配置，避免调用方后来修改列表而改变权限。登录 cookie 使用 HttpOnly、SameSite=Strict 和一小时有效期，实际仍是本地令牌会话，不是企业身份管理系统。

`demo` 明确使用合成样例并给本地访问者演示管理权限。不要将这个模式当作真实数据服务的认证方式。CLI 两种模式都只监听 `127.0.0.1`。

## 数据分页与版本一致性

`GET /entities` 保持列表响应，增加 `offset` 与 `limit`：默认 100 条，最多 1000 条。响应头 `X-Total-Count` 给出总量，`X-Revision-Id` 给出本次读取版本。读取下一页时传回该 `revision`，避免新版本发布造成跨页重复或遗漏。

目录和复核页面每页 100 条，支持前后翻页；复核可以按状态筛选，翻页链接保留版本。对历史页面提交的修改仍须经过服务端版本检查，不能更改历史发布结果。回归覆盖 105 个实体、翻页之间发布新版本、原版本无遗漏读取以及非法分页参数。

v0.2 的分页仍加载完整版本 JSON。v0.3 将企业目录和详情切换到按 revision 固定的关系投影，准备阶段写入，发布前验证，查询直接执行数据库分页；旧版本首次读取时回填一次。分页与详情的就绪路径不再读取完整 JSON。发布后的正常读取信任已验证的数据库投影，完整审计可调用 `projection_status(verify=True)`，修复派生索引可调用 `rebuild_query_projection()`。设计和故障边界见 [ADR 008](../decisions/008-query-projection.md)。

任意位置的名称/别名包含搜索仍扫描精简后的搜索值；深分页仍使用 OFFSET，尚无服务端游标。复核页面和固定版本导出继续读取完整版本文件，不能把企业目录的性能结果推广到这些操作。

## 可选混合召回的明确限制

`POST /match-runs` 新增 `candidate_mode`，默认 `fixed`。选择 `hybrid` 时，服务须通过 `--candidate-model` 配置训练集冻结的 `FrozenNameRetriever`。例如：

```sh
entitybridge serve --model artifacts/reports/experiment/model --candidate-model artifacts/reports/experiment/candidate_model
```

其中目录必须来自自己的已完成训练，不能从请求中临时指定任意文件。模型生成与完整实验命令见 [匹配审查](MATCHING_AUDIT.md)。只有选择 Splink 方法时才需要 `--model`。

混合检索扩大候选，但本轮实验的自动匹配 F1 下降。因此此模式所有评分边明确标记 `auto_merge=False`，保留真实分数并进入复核，即使分数是 1.0 也不自动归并。人工明确接受仍可合并，撤销仍可纠错。模式切换可能改变自动归并形成的分区，结果必须先准备再由管理员发布。

全局 top-k 受其他记录影响，不符合原局部 blocking 的增量前提。混合运行始终全量评分与解析，策略摘要含模型、候选配置和自动归并标志；没有伪造局部增量等价。默认检索上限 20,000 条记录和 100,000,000 次跨源组合，超限明确拒绝。它目前是复核候选扩展，不是百万级检索引擎。

## 仍需进一步建设

当前长任务同步执行；没有持久队列、任务重试和取消。复核和导出尚有全量文件读取成本，关系投影也增加了准备写入和发布验证成本。令牌从环境变量配置，缺少用户生命周期、企业 SSO、会话撤销管理与多租户隔离。公开 CI 覆盖合成行为与安装包，不能代替线上压测、备份演练和安全测试。

本轮新增权限、分页和混合复核流程回归；完整验证数量以该版本交付记录和 GitHub CI 实际运行结果为准。测试通过意味着已覆盖的行为符合契约，不能证明没有其他 bug。
