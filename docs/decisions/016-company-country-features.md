# 公司国家规范化与可解释评分

2026-09-15。国家字段原来最长 10 字符，API 会拒绝 `United States of America`；即使绕过接口导入，原始字符串硬比较也会把 `USA` 与完整名称当作冲突。现将输入上限改为 128，原始值仍写入不可变来源记录。新增显式 `fixed_iso` / `hybrid_iso` 候选模式，使用 pycountry 24.6.1 的 ISO 3166 精确字段映射。未知名称保留独立比较键，不做模糊地理推断，不把香港、台湾或其他分别编码地区并入别的编码。

原有 `fixed` / `hybrid` 行为和历史规范化版本不变。ISO 比较只投影候选输入，评分证据仍保留原始国家；候选规则和策略哈希记录新比较方式。ISO 模式均全量重算并强制人工复核，不能通过高分自动合并，也不自动发布。

公司名称特征参考 [ING EntityMatchingModel](https://github.com/ing-bank/EntityMatchingModel/tree/aa7c6e89f462d013c3f9fc308dd6d78a74620ae6) 的标准化、词汇特征与监督评分设计。直接使用 MIT 许可的 cleanco 2.3 识别法律后缀；保留原名称的 11 个特征，并增加法律后缀处理后的编辑/词集/Jaro-Winkler 相似度、词重合、训练集 IDF 加权重合、简称、长度、后缀移除指示和数字词冲突，共 22 个特征。法律后缀移除不是同一法人证据。

这不是 ING 全系统或 XGBoost 的复刻，也不是 SOTA 声明。有限对照包括原有逻辑回归、仅改变国家比较的逻辑回归、22 特征逻辑回归和固定 100 棵浅树的 sklearn 梯度提升。所有模型只学习 MaDI 训练标签；IDF 只看训练记录。验证集按依赖组件拆为概率校准与阈值选择两部分，后者决定模型，不读外部测试来选择。

新增 `FrozenCompanyMatcher` 以有界 JSON 保存系数或树结构，校验模型哈希、特征版本、依赖版本、国家映射哈希和非有限数值；树加载拒绝环和异常节点。推理不加载 pickle。`method=company` 接入 API、后台任务、CLI 和任务表单，部署者需显式配置模型目录；默认模型未替换。模型证据含特征值和规范化国家比较，模型高分仍必须人工确认。后台任务继续核对提交时的流水线与模型指纹，模型轮换使旧任务失效。

研究结果见 [完整对照](../evaluation/COMPANY_OPTIMIZATION_RESULTS.md)。当前新增特征没有稳定胜过原模型，NIST 外部迁移仍有较多误合并，因此保留研究选项；不能据此启用自动归并。已有真实人工训练入口和新研究训练入口是不同数据协议，不混用研究标签与用户判断。
