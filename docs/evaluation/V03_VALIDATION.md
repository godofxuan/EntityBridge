# v0.3 验证记录

本轮将公开部分标签评测、可重建查询投影和历史查询语境作为独立验证对象。结果不会改写 v0.2 及更早实验的原始证据。

## 公开数据评测

Fodors–Zagats 与 DBLP–ACM 已完成实际下载、文件哈希校验、已知实体划分、四种评分器和三条候选轨道的运行。模型只使用训练数据，阈值只使用验证标签。未知配对单独计数，不被补成负例。

首次运行暴露精确名称基线可被阈值零改成接纳非同名的问题。保留 v1 原始结果，修复为阈值 1 或全部拒绝后运行明确标记的 v2 重放；其余三种评分器的 TP/FP/FN/TN 与 v1 相同。新增契约回归覆盖该问题、全部拒绝选项、未知预测和测试标签禁入阈值选择。

[完整结果和解释边界](PUBLIC_BENCHMARK_RESULTS.md) · [协议](EVALUATION_PROTOCOL.md) · [全部证据索引与哈希](evidence/public_benchmarks_v03/INDEX.json)。索引包括两轮报告、冻结配置、执行协议和当时评测源码 ZIP；不包含原始数据或记录文本。

## 真实服务整合与查询

真实 GLEIF/Companies House 各 5,000 条记录在 PostgreSQL 17.11 运行，产生 13,033 个候选。导入、匹配、准备、发布、固定版本查询及导出完成，七项完整性检查通过，测试 schema 已清理。

流程约 17.88 秒，使用进程内 FastAPI TestClient；这是实际数据库和模型整合，不是网络负载测试，也不度量业务匹配精度。报告保留了 Splink 未完全训练比较级别、进程内存及产物/数据库大小。[本轮报告](evidence/public_benchmarks_v03/real_workflow_10k_v03.json)

独立查询比较使用 10,000 条合成记录、5,000 个实体、同一冻结 revision，四种查询各交替执行 25 对，逐次比较完整响应。第一页 p50 从 64.07 ms 降至 2.09 ms，就绪查询不再读取完整 JSON；旧版本第一次回填约 495.42 ms，单独计量。范围为本机 SQLite 预热查询，不推断生产吞吐或 PostgreSQL 获得相同倍数改善。[ADR 与故障验证](../decisions/008-query-projection.md)

## 已修复的指标输入缺陷

完整聚类评估原先未拒绝同一簇中的重复成员，可产生超过 1 的 B³ 数值。现要求非空簇、无重复成员、分区互斥且完整覆盖真值；新增有效分区的 B³ F1、成对指标、拆分和完整实体恢复统计。这些指标要求完整实体真值，不能套用到本轮只有部分标签的配对基准。

## 历史页面语境

修复历史目录搜索未携带 revision、历史详情顶部版本与正文不一致，以及旧 ID 去向链接未固定所依据的发布版本。回归通过真实发布和后续来源变更检验页面控件的提交与跳转，确保浏览中的版本语境不会静默切换。

## 交付检查

最终本机完整测试 **158 passed**，实际 PostgreSQL Store 与迁移/进程恢复测试均已启用；158 并非全部属于 PostgreSQL。剩余两项警告来自第三方测试客户端弃用提示。[本机验证摘要](evidence/public_benchmarks_v03/local_validation.json)

最终 wheel 在源码目录之外导入，并用已发布 v0.2 wheel 创建的数据库实际升级至 0003、回填和完整核验查询投影，检查数据保留以及 UI/API。安装包内 21 个应用文件与最终源码逐字节一致。[安装包验证](evidence/public_benchmarks_v03/wheel_v03_validation.json)

测试涵盖 SQLite/PostgreSQL 迁移、发布前投影校验、历史成员读取、并发旧版本回填、失败事务回滚及进程终止恢复。公开 CI 分别检查跨平台合成行为、实际 PostgreSQL 和安装包；远程是否通过以对应提交的 Actions 结果为准。

完整原始记录、数据库、凭据和含本机路径的日志保留在本地。公开目录只包含数值报告、复现源码与摘要；数据集软件许可证不被当作原始数据许可。测试与报告只能支持所覆盖的行为，无法证明所有使用场景均无缺陷。
