## 实际效果与用途

WDC 的固定 4,500 测试配对复测中，同一验证 F1 阈值规则下，商品逻辑回归 F1 **34.36% → Ditto 61.96%**；AP **0.380274 → 0.739056**。训练共 10 轮、按早停保留第 6 轮；原数据、旧基线权重、测试划分没有替换。

预设 `10FP + FN` 成本规则下 Ditto 成本 **797**，高于商品基线 **525**、标题基线 **492**。神经分数保留为复核候选，尚无自动归并成本改善结论。商品模型不能装入公司匹配任务，真实公司质量需要独立标签。

算法归属于 Ditto/RoBERTa 上游；本项目的工作是采用与适配、数据隔离、训练与评测冻结、产物校验、版本约束和审核接入。允许表述“采用成熟神经匹配方法并完成可复现评测”，不表述“自研领先算法”或“达到工业 SOTA”。项目整体尚未选择发布许可证，公开 GitHub 版本不等于对全部代码作出了开源许可声明。

本轮没有重跑旧 10k HTTP 负载或主公司基准；v0.4 的历史数值继续绑定其原有实验代码和参数。尚缺多种子重复实验、独立公司业务标签、真实人工效率和生产运行证据。教学中新增内容均需本人答辩验收，不能由自动化测试代替掌握情况。
